# Supervision Resources for Supervisers and Supervisees

This is an unordered list with resources for PhD candidates and their supervisors, to stimulate and facilitate conversations, agree on goals and methods, etc.

- [Questionnaire for discussing mutual expectations](https://gradstudents.ch.cam.ac.uk/files/Supervisor-Student%20Expectations%5b3%5d.pdf)
  - This questionnaire can be filled in separately by supervisor and supervisee, and stimulate a discussion about mutual expectations and responsibilities.
- [Golden Rules in PhD Supervision](https://www.universiteitleiden.nl/binaries/content/assets/sociale-wetenschappen/graduate-school-fsw/supervisors/golden-rules-in-phd-supervision.pdf)
  - A list of recommendations for creating and maintaining a fruitful relationship between supervisor and supervisee
- [SWOT analysis for PhD candidates](https://phdcompetencemodel.nl/)
  - A tool for PhD candidates to analyze their competencies, needs, etc. (Uses spreadsheet and macros, I have not gotten it to work smoothly using LibreOffice.)
- [Collaboration Agreement Template](https://zenodo.org/records/6394789)
  - A list of questions to guide discussion about collaborations, responsibilities, etc.


Thanks to everybody who contributed! If you know of a resource that could be mentioned here, please don't hesitate to get in touch or file a PR.
